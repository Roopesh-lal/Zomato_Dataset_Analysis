🍽️ Zomato Dataset Analysis

📌 Project Overview

This project analyzes the Zomato restaurant dataset using Python to uncover meaningful insights through data cleaning, exploratory data analysis (EDA), and data visualization. The analysis helps identify restaurant trends, customer preferences, and ordering patterns.

🎯 Objectives

- Clean and preprocess the dataset.
- Perform Exploratory Data Analysis (EDA).
- Visualize key insights using charts.
- Understand customer behavior and restaurant trends.

🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

📊 Analysis Performed

- Data cleaning and preprocessing
- Handling missing values and duplicates
- Restaurant rating analysis
- Online order analysis
- Restaurant type distribution
- Cost and review analysis
- Data visualization using graphs

📂 Dataset

https://www.kaggle.com/datasets/bhanupratapbiswas/zomato

📈 Key Insights

- Identified popular restaurant categories.
- Analyzed customer ratings and ordering trends.
- Visualized important business insights using charts.

🚀 Project Outcome

This project demonstrates practical data analysis skills, including data preprocessing, visualization, and insight generation using Python
